Recording notes: rehearse once with the live system; keep the final cut **under 3 minutes**. Pause briefly while tool calls and text stream rather than hiding the latency. If a tool returns zero items or a temporary error, explain the real state and record another honest take; never overlay fake data. Use no copyrighted music.
