# Environment variables

This is the authoritative list for the current VoxOps code. No browser variable contains an AWS key, GitHub token, or API URL; the browser uses same-origin `/api/demo/chat`. AWS credentials come from the standard temporary-credential provider chain, not VoxOps-specific variables.

| Variable                                    | Used by                                                              | Local / AWS                                                                  | Secret?                             | Example format                                          | Required?                                                    |
| ------------------------------------------- | -------------------------------------------------------------------- | ---------------------------------------------------------------------------- | ----------------------------------- | ------------------------------------------------------- | ------------------------------------------------------------ |
| `VOXOPS_PUBLIC_REPOSITORIES`                | `apps/server/src/index.ts`, `lambda.ts`; parsed by `packages/github` | Set locally; CDK sets it on Runtime Lambda                                   | No                                  | `ibodev1/voxops`                                        | Yes for Runtime and local server                             |
| `VOXOPS_MCP_REMOTE_URL`                     | `chat-lambda.ts`, local `index.ts`                                   | CDK sets Chat Lambda to HTTP API `/mcp`; optional locally (loopback default) | No                                  | `https://...execute-api.eu-central-1.amazonaws.com/mcp` | Yes for deployed Chat Lambda; optional locally               |
| `AWS_REGION`                                | `demo-agent.ts`, AWS CLI                                             | Set locally for Bedrock/CLI; Lambda supplies it in AWS                       | No                                  | `eu-central-1`                                          | Recommended locally; defaults to `eu-central-1` in chat code |
| `AWS_PROFILE`                               | AWS CLI and Node credential provider chain                           | Local operator only; not set by CDK                                          | No (points to a credential profile) | `<temporary-non-root-profile>`                          | Only when using a named local profile                        |
| `VOXOPS_MCP_URL`                            | `scripts/mcp-smoke.ts`                                               | Local smoke command only                                                     | No                                  | `https://...execute-api.eu-central-1.amazonaws.com/mcp` | No; defaults to loopback `/mcp`                              |
| `PORT`                                      | local server and smoke script                                        | Local only                                                                   | No                                  | `3000`                                                  | No; defaults to 3000                                         |
| `CDK_DEFAULT_ACCOUNT`, `CDK_DEFAULT_REGION` | `infra/bin/voxops.ts`                                                | CDK context during synth/diff/deploy                                         | No                                  | `<account>`, `eu-central-1`                             | No; supplied by CDK when available                           |

Do not copy a root or long-lived AWS key into `.env`. The ignored local `.env` file is not read automatically by the application. No current GitHub App, OAuth, Alexa service-authentication, or Secrets Manager environment variable is required; older ADRs discussing them are historical.
